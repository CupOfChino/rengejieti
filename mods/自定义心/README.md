# 自定义心（插件）

让每个调查员的【心】各有一套自己的数值和名字，而不是所有人共用一颗默认心。

**这个包自带心的全部内容**（2026-09-13 从 `跑团卡特质包` 搬过来）：
【心】特质 880901、默认心状态 880901、图标 `xin_icon`、帧动画特效 `xin_glow`（48 帧）与 `xin_shine`（19 帧，旧版）、
幕间入口 880901/880902，加插件本体。**不再依赖跑团卡特质包**，但依赖 BepInEx 框架 mod（见 `docs\AI协作文档.md`）。

## 【心】气焰特效（最终版：早期素材成片）

素材换成 **2026-09-15 用 AI 视频重做的那套**（`resource\shin_v2`，20 张 1248×1664 灰底帧），比早期从游戏视频抽帧的 `xin_shine` 更贴合【心】的观感。

| 项 | 值 |

> 想调快慢只改一个数：`AnimSpeed`。例如要 4 秒一圈就填 `0.075`。
> 想调高低：改帧图**底部留白**（1px 留白 ≈ 0.5px 位移；1% 角色身高 ≈ 3px 留白），或改 `AnimSize` 改整体大小。
> **编辑器导出的 txt 一定会把 `AnimSize` 重置成 1**（2026-09-15 又踩了一次，特效当场放大 2.4 倍）。
> 用编辑器调速度/顺序没问题，但导出后记得把 `AnimSize` 改回 **0.4**。详见 `docs\心的特效参数说明.md`。

## 英文（English）

中文/繁体照旧走数据里的中文；**其它语言**时插件会把我们自己的文案切成英文（只改我们这几个编号，不碰游戏本体）：

- 数据文案：特质「心」、三个状态（Shin / Shin: Initiative / Poised）、技艺「Activate Shin」、幕间三条入口；
- 自定义心：名字 `Shin (调查员) - 后缀`，描述里的加成项和规则也都是英文；
- 插件界面：编辑窗、提示条、下拉选项。

心的英文名沿用《边狱巴士》英文版的 **Shin**。所有英文都写在 `src\XinText.cs` 一个文件里，改词只动它。
游戏里换语言后最多 10 秒生效（插件会定时重贴一次）。

本目录已经是"可直接上传"状态：`Project_Depersonal`（数据+贴图）→ 游戏内「众创/编辑模组」导入；`Uploader` 是上传元数据；
`plugins\XinEditor.dll` 是插件本体。`src\`、`tools\`、`README.md` 只是开发用，不会进上传包。

## 幕间里的三个入口

在大厅的「幕间时光」里，选中某个调查员后，度假列表里会多出三条（都不消耗幕间时间和金钱）：

| 入口 | 行为 |
| --- | --- |
| 修改当前角色的「心」buff | 打开编辑窗；这个角色还没有【心】特质的话会提示先用下面那条 |
| 添加「心」 | 给这个角色加上【心】特质（已经有了会提示） |
| 移除「心」 | 移除这个角色的「心」buff 与【心】特质，他自己那颗自定义心也会一起删掉（没有的话会提示） |

编辑窗左边是：名称（前缀固定「心（调查员名）——」，后缀自己填）、速度（1~100，必填）、
三行「下拉框 + 数值」，保存 / 重置回默认 / 关闭。右边挂一个小窗列出现有的心，每行带删除
（删除要点两下，第二下才是确认）。

校验规则：后缀不能空、不能和已有的心重名；除速度外最多三项，同一项不能选两次，
数值按上限卡（伤害加成≤5、伤害减免≤3、其余≤30）。改动在下一场战斗生效。

窗口打开期间，游戏自己的快捷键（Tab/I/P/E/Q、方向键、WASD 移动等）会被屏蔽，
免得在输入框里打字时触发游戏功能；这段时间只认 **Esc**——按一下关掉这个窗口。
打开窗口时光标会直接落在"后缀"输入框里，省得再点一下。

## 它怎么工作

1. 进战斗时，游戏会给带【心】特质的角色挂上状态 880901；
2. 插件拦下这一步，查这个角色的 `RoleLibraryKey` 有没有对应的自定义心；
3. 有就换成运行时 new 出来的那颗状态（名字、数值都是现拼的），没有就原样走默认心。

【心】的开关判定（2026-09-14 修，规则同样适用于默认心）：

| 时点 | 规则 |
| --- | --- |
| 进入战斗那一刻 | 精神值已经处于**衰弱 / 衰竭** → 不挂【心】 |
| 每回合开始 | 正常 → 扣 1 点精神值维持；衰弱 / 衰竭 → 解除【心】并恢复 5 点精神值 |
| 战斗中精神值刚掉进衰弱 / 衰竭 | 当场解除（同样恢复 5 点） |
| 战斗中倒下 | 解除【心】，不补精神值（**重伤不解除**：只要精神值没垮，心就还在） |
| 战斗结束 | 解除【心】并恢复 5 点精神值 |

同一套规则写在**两份**地方：默认心在数据 `Game/Buff/880901.txt`，
自定义心在插件 `src/HeartBuffBuilder.cs` 里运行时生成——改规则时两边都要改。

### 特质沉睡时：用技艺行动点亮【心】

【心】特质**醒着**时照旧：进战斗自动挂【心】，不用管。
特质**沉睡**时不再自动挂状态，而是在这场战斗里多出一条技艺行动：

| 项 | 值 |
| --- | --- |
| 行动名 | **激活「心」**（战斗技能 880904，行动类型＝技艺） |
| 对象 | 固定自己，无需检定 |
| 选定技能时 | 本回合速度 **+50**（临时，和「诱敌」同一套机制，用于抢先手） |
| 行动结束时 | 消耗 **5 点精神值** → 获得【心】 → 获得 **4 点护甲**（状态「蓄势」880906，图标用原版护甲图标；**下回合开始时扣掉并消失**，战斗结束、死亡前也会扣掉） |
| 不能用的时机 | 身上已经有【心】（默认心或自己的自定义心都算）、或精神值处于衰弱/衰竭 |
| 使用次数 | 不限制（只要条件满足） |

数据：`Game/BattleSkill/880904.txt`（技能）+ `Game/Buff/880905.txt`（速度）/`880906.txt`（护甲）；
「按角色决定挂哪颗心」这种动态逻辑在插件 `src/HeartBattleSkill.cs` 里。

自定义心的内容存在：

```
%USERPROFILE%\AppData\LocalLow\MeowNature\Depersonalization-Release\XinEditor\hearts.cfg
```

按调查员的稳定编号（`RoleLibraryKey`，建角色时生成的 GUID）存，换存档不会串号。
游戏自己的存档是加密的 ES3，插件塞不进去，所以只能放在这里。

## 能加的数值

速度是固定项，另外最多选 3 项：

| 项目 | 上限 | 游戏内部字段 |
| --- | --- | --- |
| 伤害加成 | 5 | 额外属性 104 |
| 伤害减免 | 3 | 状态减免（普通/爆炸/法术 各减 N） |
| 速度 | 100 | 额外属性 119 |
| 闪避 | 30 | 额外属性 118 |
| 意志 | 30 | 基础属性 POW 4 |
| 神秘学 | 30 | 技能 502 |
| 斗殴 | 30 | 技能 101 |
| 射击 | 30 | 技能 102 |
| 运动 | 30 | 技能 201 |

心的名字固定是「心（调查员名）——后缀」，后缀自己起，重名会被拒绝。

## 怎么改 / 怎么测

```powershell
# 编译（产物 plugins\XinEditor.dll）
powershell -File "tools\build.ps1"

# 编译并挂到已启用的宿主 mod 上做本地测试
powershell -File "tools\build.ps1" -InstallHost 2919360679

# 测完撤掉
powershell -File "tools\build.ps1" -UninstallHost 2919360679
```

改完必须重启游戏。插件日志在 `BepInEx\LogOutput.log`（宿主 mod 那边的 BepInEx 目录）。

开发期有个开关：第一次运行时会自动给大厅第一个调查员生成一颗测试心
（伤害+5、速度+40、减伤2、神秘学+20），用来确认数值真的生效。开关在插件的配置文件里。
