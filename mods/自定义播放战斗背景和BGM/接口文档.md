## 1. 幕间入口与旧接口

本 mod 会在幕间时光里挂三条入口。每条都有一个**键**（key）：

| 键（常量） | 值 | 对应幕间入口 | 幕间数据编号 |
| --- | --- | --- | --- |
| `DomainApi.MenuAdd` | `"add"` | 添加「领域」 | `InterludeVacat 881003` |
| `DomainApi.MenuEdit` | `"edit"` | 编辑自定义战斗背景和BGM | `InterludeVacat 881002` |
| `DomainApi.MenuRemove` | `"remove"` | 移除「领域」 | `InterludeVacat 881004` |

### 1.1 开关入口

```csharp
DomainApi.SetMenuEnabled(string menuKey, string requester, bool enabled);
DomainApi.IsMenuEnabled(string menuKey);
```

- `requester` 填自己的模组名（写进日志，便于排查）；
- 任何一个模组设为 `false`，这个入口就不展示；
- 没注册过任何开关 = 默认可用。

### 1.2 重写入口行为

```csharp
DomainApi.SetMenuOverride(string menuKey, string requester, Action<HeroRoleData> handler);
DomainApi.ClearMenuOverride(string menuKey, string requester);
```

- 注册后，玩家点这条入口时执行你的 `handler`（参数是选中的调查员）；
- 同一个入口重复注册时，最后注册的生效；
- 入口被关闭时，重写不会被调用。

## 2. 领域运行时 API：能做什么

从 2026-10-18 起，其它模组可以**完全不经过玩家编辑窗**，自己注册一套领域：

- 自定义背景（`mp4 / png / jpg`）；
- 自定义 BGM（`ogg / mp3`，可循环）；
- 自定义领域效果（友方 / 敌方 / 代价，复用本 mod 的效果模型）；
- 自定义展开时角色头顶文字 + 画面边缘暗角（「领域展开——后缀」，后缀逐字交错上下浮动）和一次性音效；
- 在任意战斗方法里直接展开；
- 预先绑定到某个战斗技能 / 法术，使用该行动时自动展开；
- 只播放背景或只播放 BGM；
- 查询当前领域、停止播放。

> **边界**：背景层使用战斗相机，所以 `ExpandDomain` / `PlayVisual` / `PlayBackground`
> 只能在战斗场景中调用（当前不在战斗会返回 `false` 并写日志）。
> `PlayBgm` 不依赖战斗相机，任意场景都能切歌；战斗结束或 `StopPlayback` 时复原。
> 非战斗场景没有“战斗结束”这个时机，作者需要自己在合适的节点调用 `StopPlayback`。

外部定义不要求角色拥有【领域】特质，也不要求玩家先配过领域。
领域效果对**施法者所属阵营**结算：玩家施法时“友方/敌方”就是玩家队/敌人；
怪物施法时则反过来，以怪物所在的当前波次为友方。

## 3. 注册一套领域

### 3.1 `DomainDefinition`

```csharp
public sealed class DomainDefinition
{
    public string DisplayName;              // 状态栏/日志里的领域名；留空用 id

    public string AssetRoot;                // 相对路径的根目录；可留空
    public string BackgroundPath;           // mp4 / png / jpg
    public bool   HalfScreen;               // 只占上半屏（仅视频生效）
    public string BgmPath;                  // ogg / mp3
    public bool   BgmLoop;                  // BGM 是否循环
    public bool   ShowDialogOnOpen;         // 展开时显示头顶文字 + 边缘暗角（不绘制黑底）
    public string DialogSuffix;             // 文字框中的后缀；留空用 DisplayName
    public bool   PlaySoundOnOpen;          // 展开时播放一次音效
    public string SoundPath;                // ogg / mp3 / wav

    public DomainTargetType AllyTarget;     // None / Caster / AllAllies
    public bool   EnemyTarget;
    public int    AllyEffectType;           // DomainEffectPreset 常量或 BuffOffset + buffId
    public int    AllyEffectValue;
    public int    EnemyEffectType;
    public int    EnemyEffectValue;

    public DomainCostType CostType;         // None / Hp / San / Mp
    public int    CostValue;
}
```

路径规则：

1. **绝对路径**：直接使用，例如 `D:\MyMod\assets\bg.mp4`；
2. **相对路径 + `AssetRoot`**：按 `Path.Combine(AssetRoot, 相对路径)` 解析。
   推荐在插件 `Awake()` 里把自己的 mod 目录填进 `AssetRoot`；
3. **相对路径、没有 `AssetRoot`**：按本 mod 玩家资源库的 `Background` / `Bgm` / `Sfx`
   目录解析（方便复用玩家已经导入的文件）。

### 3.2 注册 / 更新 / 注销

```csharp
bool DomainApi.RegisterDomain(string requester, string id, DomainDefinition definition);
bool DomainApi.UnregisterDomain(string requester, string id);
```

- `requester` 用自己的模组名；`id` 用自己的定义 id。两者组成全局命名空间；
- 同一个 `requester + id` 重复注册会**更新**旧定义；
- 注册表只在内存里，不写玩家 `profiles.cfg`；每次启动游戏都要在插件 `Awake()` 里重新注册；
- 注册时背景 / BGM 文件暂时不存在只会写警告，真正展开时按“缺文件跳过”的容错处理；
- 正在生效的领域不能直接更新，先 `StopPlayback`，再重新注册；
- 注销不会删除你的资源文件（本 mod 只管理玩家编辑窗导入的资源库）。

### 3.3 一个最小例子

```csharp
using System.IO;
using System.Reflection;
using CustomBattleBg;

private const string MyMod = "我的模组";
private const string MyDomain = "红月";

void Awake()
{
    string modDir = Path.GetDirectoryName(Assembly.GetExecutingAssembly().Location);
    DomainDefinition def = new DomainDefinition();
    def.DisplayName = "红月领域";
    def.AssetRoot = Path.Combine(modDir, "assets");
    def.BackgroundPath = "redmoon.mp4";
    def.BgmPath = "redmoon.ogg";
    def.BgmLoop = true;
    def.ShowDialogOnOpen = true;
    def.DialogSuffix = "无量空处";
    def.PlaySoundOnOpen = true;
    def.SoundPath = "open.ogg";

    def.AllyTarget = DomainTargetType.AllAllies;
    def.AllyEffectType = DomainEffectPreset.PhysicalDamageBonus;
    def.AllyEffectValue = 3;          // 3 层 = +30%

    def.EnemyTarget = true;
    def.EnemyEffectType = DomainEffectPreset.PhysicalVulnerable;
    def.EnemyEffectValue = 2;         // 2 层 = +20% 受伤

    def.CostType = DomainCostType.Mp;
    def.CostValue = 5;
    DomainApi.RegisterDomain(MyMod, MyDomain, def);
}
```

### 3.4 领域效果常量

`DomainEffectPreset` 与本 mod 编辑窗使用同一套编号：

| 常量 | 含义 |
| --- | --- |
| `PhysicalDamage` / `MagicDamage` | 每轮开始时造成物理 / 法术伤害 |
| `PhysicalDamageBonus` / `MagicDamageBonus` | 伤害强化（每层 10%） |
| `PhysicalDamageReduce` / `MagicDamageReduce` | 伤害守护 |
| `PhysicalDamageDown` / `MagicDamageDown` | 伤害弱化 |
| `PhysicalVulnerable` / `MagicVulnerable` | 易损（受到伤害增加） |
| `MpDrain` / `MpRestore` | 扣除 / 恢复魔法值 |
| `SanDrain` / `SanRestore` | 扣除 / 恢复精神值 |

手选游戏 buff：

```csharp
def.EnemyEffectType = DomainEffectPreset.BuffOffset + 436;  // 具体 buff 编号
def.EnemyEffectValue = 2;                                   // 层数
```

效果时机与本 mod 玩家配置一致：

- 增减益类（层数）每轮开始施加、回合结束自动解除；
- 造成伤害 / 资源结算每轮开始结算；
- 不随回合衰减的具体 buff 在展开时挂一次，领域结束时收回；
- `CostValue` 在展开时和每轮开始各结算一次，负数按 0 处理。

## 4. 在任意方法里展开 / 播放

### 4.1 完整领域

```csharp
bool DomainApi.ExpandDomain(
    string requester,
    string id,
    BattleRole caster,
    string reason = "");

bool DomainApi.ExpandDomainForRole(
    string requester,
    string id,
    RoleData caster,          // 只有 RoleData 时用这个，内部走 caster.Role
    string reason = "");
```

- 不要求【领域】特质，不要求玩家配置；
- 会切换背景 + BGM、挂领域状态、按定义结算领域效果；
- 每次调用都会重新展开（刷新效果）；同一个施法者重复调用也会重新播放；
- 返回 `false` 通常表示：没注册、不在战斗、施法者为空、资源/参数无效。
  函数永远不向调用方抛异常，详细原因看 BepInEx 日志。

典型用法：自定义战斗技能的 `BattleSkillBaseOption.Run` 里：

```csharp
public override async Task Run(BattleActiveBehaviorData data, ParamTransmitionData param)
{
    DomainApi.ExpandDomain(MyMod, MyDomain, data.Self, "我的技能");
    await Task.CompletedTask;
}
```

### 4.2 战斗开始 / 回合开始等时机

可以直接在这些时机调用 `ExpandDomain`：

- `BattleFightContent.Run()` 里的 `BeforeBattleStart` / `BattleStart` 触发；
- 回合开始 / 行动开始 / 行动结束等战斗内回调；
- 你自己的 Harmony Prefix / Postfix，只要此时 `DomainApi.IsBattleReady()` 为 `true`。

原因：游戏是**先创建 `BattleFightContent.Room`，再调用 `Run()` 触发 `BattleStart`**，
所以 BattleStart 时战斗相机已经可用，背景层能正常挂载。

唯一要注意的是更早的 `GameWorld.EnterBattle` Prefix：那一刻战斗房间可能还没创建，
此时调用会返回 `false`。把请求延后到 `BattleStart` / `BeforeBattleStart` / 战斗场景加载完成后
再调用即可；用 `DomainApi.IsBattleReady()` 可以先判断。

### 4.3 只播放画面 / 只播放 BGM

```csharp
bool DomainApi.PlayVisual(requester, id, reason);     // 背景 + BGM，战斗内
bool DomainApi.PlayBackground(requester, id, reason); // 只切背景，战斗内
bool DomainApi.PlayBgm(requester, id, reason);        // 只切 BGM，任意场景
bool DomainApi.StopPlayback(requester, reason);        // 停止当前领域并复原
```

- `PlayVisual` / `PlayBackground` 不会挂领域状态，也不会施加领域效果；
- `PlayVisual` / `PlayBackground` 在非战斗场景返回 `false`；
- `PlayBgm` 可以独立使用；战斗结束时本 mod 会尝试恢复原来的 BGM；
- `StopPlayback` 会移除当前领域效果、隐藏背景层、恢复 BGM；任何模组都可以调用，
  请在确定要接管当前场景时使用。

### 4.4 任意角色头顶文字

不要求先注册领域，也不需要领域正在生效：

```csharp
bool DomainApi.ShowHeadText(
    string requester,
    string text,
    BattleRole caster,
    float duration = 2.5f);

bool DomainApi.ShowHeadTextForRole(
    string requester,
    string text,
    RoleData caster,
    float duration = 2.5f);

bool DomainApi.HideHeadText(string requester = "");
```

- 有行动框（技能牌 / 编辑行动牌）时，文字放在行动框上边框中点上方；
- 没有行动框时，文字挂在角色 `RoleModel.Trans_Head` 上方；
- 文字量变化时自动计算 preferred size；
- 每帧跟随角色移动，底边与锚点保留少量间距；
- 支持 `<b>` / `<color>` 等 Unity 富文本标签；
- 不要求 caster 有【领域】特质，适合 Boss 技能、事件或自定义行动触发。
- 当前稳定版只绘制文字 + 画面边缘暗角，不绘制黑色底框。接口名称仍保留 `ShowHeadText`。

### 4.5 查询当前领域

```csharp
bool DomainApi.IsDomainActive();
bool DomainApi.IsBattleReady();     // 战斗房间是否已经创建
DomainRuntimeInfo DomainApi.GetCurrentDomain();
```

`DomainRuntimeInfo` 字段：`Active / DisplayName / Owner / DomainId / CasterRoleKey /
CasterName / HasBackground / HasBgm / ShowOpenDialog / PlayOpenSound`。

## 5. 预先绑定“使用某个行动就展开”

不需要自己写 Harmony。注册定义后，把定义绑定到技能或法术 ID：

```csharp
// 使用战斗技能 900001 时展开「红月」
DomainApi.BindAction(
    MyMod,
    MyDomain,
    DomainActionType.BattleSkill,
    900001,
    roleKey: "",          // 留空 = 任何角色使用都触发
    roleName: "",
    roleConfigId: 0,
    reapplyEveryUse: false);
```

对应的解绑：

```csharp
DomainApi.UnbindAction(MyMod, MyDomain, DomainActionType.BattleSkill, 900001);
DomainApi.ClearActionBindings(MyMod);        // 清掉这个模组全部绑定
DomainApi.ClearActionBindings(MyMod, MyDomain); // 只清某个领域
```

### 5.1 `DomainActionBinding` 字段

```csharp
public sealed class DomainActionBinding
{
    public string Requester;
    public string DomainId;
    public DomainActionType ActionType;  // BattleSkill / AnyMagic / Magic
    public int ActionId;                 // 技能或法术 id；AnyMagic 忽略
    public string RoleKey;               // 限定调查员 RoleLibraryKey
    public string RoleName;              // 限定角色名
    public int RoleConfigId;             // 限定 RoleData.ConfigId（怪物常用）
    public bool ReapplyEveryUse;         // 每次使用都刷新
}
```

- `DomainActionType.AnyMagic` = 任意法术；
- `RoleKey / RoleName / RoleConfigId` 同时填时是“且”关系；
- 多个绑定同时匹配一条行动时，**最后注册的生效**；
- 外部绑定优先于角色自己的玩家「挂载行动」配置；
- `ReapplyEveryUse = false`：这个领域已经是当前领域时不重复展开；
  被别的领域顶掉后，再次使用可以重新展开；
- `ReapplyEveryUse = true`：每次使用都重新播放并刷新效果。

### 5.2 对象式注册（适合一次填很多条件）

```csharp
DomainActionBinding binding = new DomainActionBinding();
binding.Requester = MyMod;
binding.DomainId = MyDomain;
binding.ActionType = DomainActionType.Magic;
binding.ActionId = 12345;
binding.RoleConfigId = 90001;      // 只对某个怪物
binding.ReapplyEveryUse = true;
DomainApi.BindAction(binding);
```

## 7. 行为细节与兼容性

1. **不要求特质**：外部定义由调用方 / 行动绑定负责触发，本 mod 不会自动检查【领域】；
2. **领域唯一性不变**：同一方出现新领域时，旧领域状态与持续效果会被移除；
3. **背景层只在战斗**：外部背景不会出现在大厅/探索；需要探索背景请另做一层，避免误以为
   `PlayBackground` 能改地图场景；
4. **资源归属**：外部资源由作者自己管理；本 mod 不会复制、覆盖或删除它们；
5. **容错**：注册/播放失败只写日志并返回 `false`，不会把异常抛进游戏主循环；
6. **向后兼容**：旧的 `SetMenuEnabled / IsMenuEnabled / SetMenuOverride / ClearMenuOverride`
   签名和行为保持不变。
7. **展开表现**：`ShowDialogOnOpen` 使用本模组的角色头顶文字 + 画面边缘暗角，
   内容固定为「领域展开——DialogSuffix」；文字按 preferred size 自动排版，有行动框时位于行动框上方，
   没有行动框时位于角色模型顶边上方；不绘制黑色底框。后缀红体加粗并逐字交错上下浮动，
   文字约 2.5 秒自动关闭。独立 Canvas 使用
   Screen Space - Overlay，`sortingOrder = 30000`，因此战斗开始阶段也能盖在行动槽 HUD 之上。
   原版 `UIScreenTipPanel` 全屏黑屏和 `RoleModel.ShowDialog` 角色对话框的尝试记录见仓库协作文档。`PlaySoundOnOpen`
   走游戏 SFX 通道，只播放一次；外部音效支持 `ogg / mp3 / wav`，默认相对 `Sfx` 目录。
   只有背景实际切换成功才会播放；背景文件缺失 / 战斗相机不可用 / 图片加载失败时会跳过表现层。
8. **特质醒/睡**：外部领域不依赖特质；玩家配置的【领域】特质沉睡时只停止战斗开始自动播放，
   不阻止幕间编辑，也不阻止「领域展开」技艺和挂载行动。
