# 自定义播放战斗背景和BGM（插件）

给每个调查员配一套**自己的战斗背景 + 战斗 BGM**：特质【领域】苏醒（进战斗）时自动展开；
战斗中还能用技艺「领域展开」手动再展开一次；战斗结束（离开战斗）时背景与 BGM 都会复原。

需要 **BepInEx 框架 mod**（见 `docs\AI协作文档.md`）。

## 在大厅的幕间时光里用

选中某个调查员后，度假列表里会多出三条（都不消耗幕间时间和金钱）：

| 入口 | 行为 |
| --- | --- |
| 编辑自定义战斗背景和BGM | 打开编辑窗：命名 + 传背景 + 传 BGM + 循环勾选 + 确认/取消，右边列出现有配置（带删除） |
| 添加「领域」 | 给这个角色加上【领域】特质（已经有了会提示） |
| 移除「领域」 | 移除特质，并把他的那套配置一起删掉（没有的话会提示） |

编辑窗里能设置的：

| 项 | 说明 |
| --- | --- |
| 命名 | 固定是「调查员名——后缀」，后缀自己填，**全局不可重名** |
| 战斗背景 | `mp4 / png / jpg`。图片推荐 **1920×1080**，视频推荐 **1920×1080 MP4（H.264）**；**视频循环播放** |
| 战斗BGM | `ogg / mp3`；勾不勾"循环播放"决定它播完一遍后要不要切回原来的战斗 BGM |
| 只占上半屏 | 勾上后背景只遮屏幕上方（下方露出原背景），适合"墙上放视频"的观感 |
| 挂载行动 | 可搜索的下拉框：挑一条**战斗行动**（全部战斗技能，含其它 mod 加的技能）或**法术**（该角色已学会的，或"任意法术"）。战斗中**使用这个行动时**就展开领域——适合"放某个法术时拉开领域"的玩法 |

点「选择文件」会打开 Windows 的文件管理器，选中的文件会**自动复制**进资源库。

**资源库放在游戏存档目录里**（不是 mod 目录）——这样 Steam 更新 mod 时不会把你的资源清掉：

```
%USERPROFILE%\AppData\LocalLow\MeowNature\Depersonalization-Release\CustomBattleBg\
├─ Background\   ← 战斗背景（mp4 / png / jpg）
├─ Bgm\          ← 战斗BGM（ogg / mp3）
└─ profiles.cfg  ← 每个调查员的配置（插件自动维护）
```

> 目标文件夹里**已经有同名文件**时会问你要不要**覆盖**（覆盖后引用这个文件的配置会换成新内容）；
> 选"取消"就保留原来的文件。编辑窗底部的「**打开资源库**」按钮可以直接打开这个文件夹，不用自己找路径。
> 这些资源是**本地文件**，不会随 mod 上传到创意工坊——换电脑需要自己拷走这个目录。

### 删除资源

- 编辑窗里点「清除」：会弹提示**确认后把对应的文件一起删掉**（现在没有资源库，留着也没法重新导入）；
- 侧边栏「删除」一条配置、或幕间点「移除「领域」」：配置**和它引用的背景/BGM 文件**一起删掉；
- 只有"还有别的配置在引用同一个文件"时才会保留（正常流程下一条文件只归一条配置）。

## 战斗里的表现

- 进战斗时：所有"【领域】特质苏醒 + 配过东西"的调查员里，**只有速度最慢的那一位**会展开
  （同一时机触发时，最慢的等于最后出手，覆盖其他人）；
- **领域归属**：一场战斗里记录"当前领域是谁的"——同一个角色再触发（用技艺或挂载行动）**不会重复展开**；
  换成别人的领域时会展开并刷新归属；战斗结束/重开战斗时归属清零；
- **挂载行动**：配了"挂载行动"的角色，在战斗中使用那条行动时自动展开自己的领域（同样受归属判定约束）；
- 切换背景有**从屏幕右边缘向左铺满**的展开动画（1 秒）；图片背景还会左右缓慢轻摆
  （幅度/周期在插件配置的 `[背景摇晃]` 里调，视频不晃）；
- 编辑窗还能勾「**只占上半屏**」（**只对视频生效**）：
  - 视频：**整幅视频按比例缩小**放进屏幕上方区域、四周留黑边（黑边厚度由 `[背景显示] 视频黑边` 控制，默认上下各 5%），
    视频画面**不会被裁掉**——"墙上挂了一块屏幕"的观感，角色仍然站在原来的地面上；
    上方区域的高度由 `[背景显示] 上半屏比例` 控制（默认 0.55）；
  - 图片：**忽略这个选项**，始终全屏铺满（保持比例、超出裁切）；
- 音乐与声音：
  - 配了 BGM → 直接切换成这首（勾了循环就一直播到战斗结束；没勾就播完一遍自动切回**原有的战斗 BGM**）；
  - **视频背景会播放自己的音轨**，并且像 BGM 一样**接管音乐通道**——没配 BGM 时游戏自带的战斗 BGM 会被关掉；
    配了 BGM 就是"视频原声 + 你的 BGM"一起响；
  - 图片背景 + 没配 BGM → 游戏自带 BGM 照常，不做任何改动；
- 战斗中每个有配置的角色都会获得技艺「**领域展开**」（不消耗、可反复用），
  用一次就把自己的领域重新展开一遍（后展开的覆盖先前的）；
- 战斗结束（离开战斗）时：背景层销毁（原背景自然复原）；
  BGM 与"战斗开始时记录的那一首"比较，不同才复原。
- 任何环节出错（配置缺、文件丢了、格式不支持……）都只写日志跳过，**不会打断游戏**。

## 给其它模组作者的接口

幕间那三条入口可以被其它模组**开关**或**重写**（例如：关掉本 mod 的编辑面板、换成自己模组的界面）：

```csharp
using CustomBattleBg;

DomainApi.SetMenuEnabled(DomainApi.MenuEdit, "我的模组", false);            // 关掉"编辑面板"入口
DomainApi.SetMenuOverride(DomainApi.MenuAdd, "我的模组", delegate(HeroRoleData role) { ... }); // 重写"添加领域"
```

- **投票规则**：任何一个模组设为关闭，入口就不再显示（谁关的会写进日志，方便排查）；
- 完整 API、反射调用示例和细节见 `docs\自定义播放战斗背景和BGM-接口文档.md`。

## 怎么改 / 怎么测

```powershell
# 编译（产物 plugins\CustomBattleBg.dll）
powershell -File "tools\build.ps1"

# 编译并挂到已启用的宿主 mod 上做本地测试（2919360679 = 兑换幕间时间那个）
powershell -File "tools\build.ps1" -InstallHost 2919360679

# 测完撤掉（只删自己装进去的文件，不动宿主原有的东西）
powershell -File "tools\build.ps1" -UninstallHost 2919360679
```

改完必须重启游戏才会生效。插件日志在宿主的 `BepInEx\LogOutput.log` 里（搜 `自定义播放战斗背景和BGM`）。

本地测试和正式安装用的是**同一个资源库**（游戏存档目录下的 `CustomBattleBg`），
所以测试时导入的资源，装正式版之后还能直接用。
