# 「心」特效：现状说明与外部咨询材料

> 用途：把现状一次性说清楚，方便交给外部（另一个 AI / 美术）给建议。
> 配套文件：对比图 `mods\跑团卡特质包\tools\preview\compare.png`、
> 官方参数 `E:\lim\_save\shin_effect.json`、生成脚本 `mods\跑团卡特质包\tools\build_heart_glow.ps1`。

## 1. 想要的效果

《人格解体》里一个叫「心」的战斗状态，挂在调查员身上。目标是**还原《边狱巴士》里同名状态（Shin）的视觉**：
角色身后一团金色光芒，丝丝缕缕往上流动，底部更深、顶部更亮，带少量零星亮点。

## 2. 目标游戏的硬限制（最关键）

《人格解体》**没有粒子系统**，mod 只能提供"帧动画"特效：

| 项目 | 说明 |
| --- | --- |
| 特效形式 | 一张一张 PNG 按顺序播（`Game/ExtraAnim/<名字>.txt`） |
| 可调项 | 每帧时长（秒）、是否循环、整体缩放 `AnimSize`、动画速率 `AnimSpeed`、渲染排序层/序号 |
| 渲染 | 单个 SpriteRenderer 换贴图；**没有加法混合、没有噪声模块、没有速度曲线** |
| 挂载点 | 角色身上的固定挂点（我们用的是"身体正中"），特效尺寸以角色为参照 |
| 尺寸换算 | 我们的画布 512×512、`AnimSize=0.302` → 覆盖约 1.55 世界单位；SD 小人高约 1.3 单位（画布上约 429px，1px≈0.00303 单位） |
| 帧数预算 | 64 帧以内没问题（48 帧 512² PNG ≈ 3~7 MB） |
| 播放速度 | 现在 0.2 秒/帧；一圈 48 帧 = 9.6 秒 |
| 排序 | 现在放在角色模型**下面**（`SortName=Chara`、`SortOrder=-100`） |

**所以要做的是：把"粒子效果"翻译成"一段能循环的逐帧动画"。** 关键难点是丝缕感——没有噪声模块，只能用形状/透明度/运动来伪造。

## 3. 官方（Limbus）原版参数

来源：预制体 `Fx_BaseFx_Buff_Sin`（`EffectList_a1c9p2` 里 label="Shin"）。三层结构：

```
Fx_BaseFx_Buff_Sin            根（不发光，只是容器）
└ Pivot
  ├ Move_Shaodw1              地面层：寿命 4~4.5 秒、尺寸 6.5、发射 0.8 个/秒、透明度 0→0.208→1
  └ Particle                  可见粒子层（下面这些数值都是它）
```

可见粒子层（完整）：

| 项目 | 数值 |
| --- | --- |
| 寿命 startLifetime | 两常量 **1.0 ~ 2.0 秒** |
| 初速 startSpeed | 两常量 **2.5 ~ 5.0** |
| 初始大小 startSize | 两常量 **0.05 ~ 0.09**（开启 3D Size） |
| 初始旋转 | **0 ~ 2π（整圈随机）** |
| 重力 | **0** |
| 最大粒子数 | 1000 |
| 发射 | **5 个/秒**，另有 t=0 的 **1 个 Burst** |
| 发射形状 | **Circle**，半径 **0.7**，radiusThickness 1.0 |
| 大小随寿命 | 曲线 **(0,0) → (0.34,1.0) → (1,0)** |
| 颜色随寿命 | 单一金色 RGBA(1.0, 0.75, 0.25, a=1)（即 #FFBF40）；透明度按数据是"靠缩小消失" |
| 噪声 Noise | enabled；strength **0.5~1.0**、strengthY 1.0、frequency **1.5**、**damping 开**、octaveMultiplier 0.5、octaveScale 2.0、scrollSpeed **0.3**、positionAmount **1.0**（rotation/size amount 都是 0）、remap 未启用 |
| 渲染 | 材质 `Fx_M_Public_Compact_RGB_Alp`（预制体里贴图槽是空的 → 贴图/颜色由运行时给）；排序层 ID 905029585、order 2、renderMode 0 |

补充：`Start Color` 与 `Color over Lifetime` 会相乘，所以最终颜色比 #FFBF40 更暖（约 #FFA710）。

| 版本 | 做法 | 结果 |

| v1 `xin_shine`（19 帧） | 你给的视频抽帧 + 首尾交叉淡化 | **最像参考图**，但是位图素材，放大发虚、节奏受原片限制 |

## 5. 当前生成器的参数（`build_heart_glow.ps1`）

| 层 | 参数 |
| --- | --- |
| 氛围光（2 个椭圆） | 尺寸 0.46H / 0.62H，透明度 13~20/255，颜色 #FFB046 / #FFC46E |
| 光缕（9 道） | 宽 0.10~0.20H、拉伸 2.2~3.2、寿命 3~4.5 秒、上升 0.12~0.22H/秒、摆幅 0.03~0.06H、透明度峰值 0.18~0.40，颜色 #FFD678 |
| 火花（48 个铺满一圈） | 基础尺寸 0.020~0.035H、寿命 1.2~2 秒、上升 0.35~0.60H/秒（末速 0.18 倍）、横向漂移 ±0.04H/秒、正弦摆幅 0.02~0.05H（0.7~1.5 次/秒）、颜色 #FFBF40 或 #FFA710 |
| 地面（1 个椭圆） | 0.62H × 0.14H，透明度 15/255，颜色 #FFAA3C |
| 循环 | 48 帧 × 0.2 秒 = 9.6 秒；每个粒子用"出生时刻 + 相位"保证首尾相接 |

（H = 角色可见高度，画布上约 429px）

## 6. 需要外部给的建议

**核心问题：在没有粒子系统、没有噪声、没有加法混合的逐帧动画里，怎么做出"丝缕状的火焰光柱"？**

具体想要：

1. 每一层该怎么设计（画几层、每层画多少笔、宽高比、透明度、颜色），才能既有"丝缕"又不糊成团；
2. 丝缕的**形状**大概长什么样（比如长条水滴 / 弯曲的带子 / 分叉的火舌），以及它们该怎么动（速度差、摆动频率）；
3. 如何用透明度曲线在帧动画里伪造"噪声扰动"的感觉（比如让丝缕的边缘随时间轻微变形）；
4. 参考图里那种"非常亮的白黄核心 + 更浅的灰白金"该怎么分配比例和位置；
5. 如果只能用 48~64 帧、512×512、0.2 秒/帧，你会怎么排这 48 帧。
