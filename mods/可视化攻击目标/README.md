# 可视化攻击目标（插件）

把战斗里的"谁要打谁"画出来：从出手方的行动槽拉一条箭头，指向这个行动要作用的目标。

人格解体在装备好行动之后，界面上只剩一个技能图标，看不出这个行动打谁；3v3 打起来时尤其看不清。
这个插件给每个已确定的行动补上指向箭头（思路参考《边狱巴士》速度骰子之间的连线）。

## 箭头怎么看

| 样式 | 含义 |
| --- | --- |
| 红色实线 | 对**敌人**的**单体**行动 |
| 红色虚线 | 对**敌人**的**范围／随机**行动（每个可能目标各一条） |
| 绿色实线 | 对**队友**的**单体**行动 |
| 绿色虚线 | 对**队友**的**群体**行动 |
| 蓝色箭头 | **干扰类**行动（原版的非伤害技艺：诱敌／魅惑／威吓／观察弱点／搜身……） |
| 黄色双箭头 | **对抗**（双方互为目标）：两个黄色箭头头在中点撞在一起 |

补充规则：

- **以自己为目标**的行动不画箭头。
- **多条箭头指向同一个目标**时会收束，只留一个箭头头。
- 虚线上的实段会朝目标方向流动。
- **投掷类行动**固定用红色（哪怕目标是队友）。

## 什么时候显示

只在**选行动阶段**显示：谁确定了行动，谁的箭头就出现，并一直留着。
开始出手（进入结算演出）时全部清除，下一轮重新出现。

## 箭头是"预告"

人格解体的目标在**装备行动那一刻**就已经定好了（包括"随机目标"技能——它底层是以对方全体为范围、
每段各随机一次，所以按范围画虚线，不逐段显示真实落点），所以箭头基本就是最终结果。

但演出前如果目标倒下、被拦截掩护、或者被擒抱，实际打的人会变。插件每帧按实时数据重画，
箭头会跟着变，但请以实际演出为准。

## 依赖

需要 BepInEx 框架 mod（创意工坊 `2925170762`）。

## 这一包还带着什么（2026-09-22 起）

除了箭头，本包还负责**茉莉专属的私货内容**：4 个特质 + **6 件专属装备** + 一整套配套状态。
原来这些是「自定义心」的插件实现的（借住在 `XinEditor.dll` 里），2026-09-22 拆到这边的插件。

**4 个特质**：百合花（880021）、白毛少女（880022）、灰暗孤影（880023）、记忆的双剑（880030）。

**6 件专属装备**：

| 装备 | 定位 |
| --- | --- |
| 葬花（880001） | 主手双剑：高伤 + 破甲，命中叠【剑痕】（护甲 / 闪避 / 运动下降、受到伤害提升），回合结束减半并补【流血】 |

## 源码

`src\` 是插件源码，`tools\build.ps1` 是编译脚本——用 SDK 里的 Roslyn 直接编译，
不联网、不需要 csproj。

```powershell
powershell -File "tools\build.ps1"                              # 只编译
powershell -File "tools\build.ps1" -InstallHost 3801085814      # 编完挂到某个已启用 mod 上做本地测试
powershell -File "tools\build.ps1" -UninstallHost 3801085814    # 测完撤掉
```
