# 多行动槽（插件 + 特质）

让战斗角色在同一幕里拥有多个行动槽：**逐槽选行动、逐槽执行**；
同一角色的所有槽共享同一个行动顺序数字；玩家侧用【速战速决】特质按速度获得额外槽。
敌方同样吃这套系统（Boss 可以一回合执行多个行动——这正是这个模组最主要的目标之一）。

需要 **BepInEx 框架 mod**（见 `docs\AI协作文档.md`）。

## 玩法：速战速决

在**幕间时光**里选中调查员，度假列表会多出两条（都不消耗幕间时间和金钱）：

| 入口 | 行为 |
| --- | --- |
| 添加「速战速决」 | 给这个角色加上【速战速决】特质（已经有了会提示） |
| 移除「速战速决」 | 移除特质（没有的话会提示） |

特质描述：「获得额外行动槽」；**苏醒**时按速度生效，**沉睡**时无效果：

| 速度 | 行动槽 |
| --- | --- |
| < 100 | 1 个（原版） |
| ≥ 100 | 2 个 |
| ≥ 300 | 3 个 |

速度在**进入战斗时**和**每一幕开始时**各读一次——也就是说，战斗中速度变化要到下一幕才影响槽数。

## 多槽怎么运作

- **选行动**：给自己角色逐槽选行动（选完第 1 个紧接着选第 2 个），全部选完才轮到下一个角色；
  中间槽的按钮会显示「确定行动 k/N」，最后一个槽恢复原版的「完成选择 / 开始战斗」。
- **出手**：同一角色的槽连续执行（槽 1 → 槽 2 → …），全部执行完才轮到下一个角色；
  行动顺序数字只显示在最左边那个槽的左上角，同一角色所有槽共用一个数字。
- **行动开始 / 结束的 buff 判定默认只做一次（首个槽）**：避免同一个角色一回合把
  "行动结束时"类效果触发多次。配置项 `EachSlotTriggerBuffs` 可以打开"每个槽各判定一次"，
  但**不建议**：可能和原版 buff 的预期冲突。
  - **原版"怀表"等额外行动道具也只对第一个行动槽生效**（首槽后触发一次）；
    **作者未实测过该场景，实际效果未知**，遇到问题请带上日志（前缀 `[多行动槽]`）反馈。
- **同一个行动可以重复装**（例如两个槽都选攻击）。配置项 `AllowDuplicateAction` 可以关掉，
  关掉后重复装同一个技能会在确认时被拦下并提示。

## 与「可视化攻击目标」兼容

不需要改动「可视化攻击目标」：本模组在运行时识别它并**接管多槽角色的箭头绘制**——
每个行动槽各画一条箭头（起点 = 该槽顶边框中心）；互指（对抗）时双方各条线汇到同一个
对抗点、左右各一个箭头头相撞（对抗点取可视化原版弧线的中点）。
可视化模组的方法签名对不上时，会打日志并退回"每个角色一条箭头"，两边都能正常跑。

## 给模组作者的接口

命名空间 `DuoActionSlot`，公开静态类 `ExtraActionSlotApi`。**完整签名、语义、事件与示例见
[`接口文档.md`](接口文档.md)**，摘要：

- 查询：`GetSlotCount` / `GetExtraSlotCount` / `IsMultiSlot` / `GetEditingIndex` /
  `IsExecuting` / `IsSlotChosen` / `IsSlotExecuted` / `IsSlotSkipped` /
  `GetSlotData`（槽的行为数据）/ `GetSlotAnchor`（槽的 UI 节点）/ `GetSlotInfos`（全部槽快照）；
- 修改：`SetExtraSlotCount` / `AddExtraSlotCount` / `RemoveExtraSlotCount`（按 `sourceKey` 记账）；
- 动态提供者：`RegisterSlotCountProvider` / `UnregisterSlotCountProvider`（每幕重算时调用一次）；
- 事件：`SlotCountChanged`（槽数变化）/ `SlotChosen`（某槽选好行动）/ `SlotExecuted`（某槽执行完）。

所有接口在任何时刻调用都安全；参数非法 / 非战斗状态只是安静返回；
槽数修改在**下一幕开始**生效（不会打断当前幕的选择 / 执行）。

## 配置与日志

插件配置在 `BepInEx\config\codex.depersonal.duoactionslot.cfg`：

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `EnableDuoActionSlot` | true | 总开关。关掉后插件完全不改变战斗行为 |
| `EachSlotTriggerBuffs` | false | 每个槽都触发行动开始 / 结束 buff。**可能有问题，不建议打开** |
| `AllowDuplicateAction` | true | 允许同一行动装进多个槽 |
| `VerboseLog` | false | 详细日志（排查问题用） |

日志前缀 `[多行动槽]`，进游戏跑一场战斗就能从日志看到：
每个角色的槽数、每个槽的选择 / 执行、HUD 视图建立与降级。
