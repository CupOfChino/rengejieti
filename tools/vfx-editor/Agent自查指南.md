# 人物特效编辑器的 Agent 自查

检查脚本用编辑器本身的画布渲染，将角色动作、特效图层和锚点保存成 PNG。它可加载左右两个角色及各自的动作，适用于检查待机、攻击、施法与受击。以下命令在仓库根目录执行。

## 查素材和打开工程

```powershell
node tools/vfx-editor/check-scene.mjs --list "夜柳"
node tools/vfx-editor/check-scene.mjs --list "圣光"
```

搜索结果包含素材的 `id`、来源、帧数和支持的动作。相同名字可能同时来自本地模组和工坊，按 `source` 确认。素材 ID 与本机目录和来源有关，在当前工作区重新查询。已有工程可直接传入。新场景可在编辑器摆好人物和图层，使用「保存工程」生成 `.vfx.json`，再基于它调整参数。

多段招式可用「添加动作」在当前时间加一个姿势切换点。选中动作轨上的某一段，可以修改动作及相对工程起点的秒数。特效可分别调整横向比例、纵向比例和两轴镜像。反手斩可沿用正手贴图并开启纵向镜像。对照色彩时可设置「背景」并关闭网格。检查脚本使用保存于工程的动作轨、图层及舞台设置。

模型目录若带有 `pose-pivots.json`，浏览器会用各帧的脚下落点对齐。键为帧文件名，坐标以原图左上角为原点，单位为像素。例如 `"pose.png": { "x": 240, "y": 566 }`。

同一帧也可添 `"eye": { "x": 187, "y": 119 }`、`"sheath": { "x": 279, "y": 249 }` 或 `"gun": { "x": 532, "y": 161 }`。选用这些挂点的图层会跟随人物切图与镜像。挂点也会出现在标尺和透明帧导出中。缺少对应挂点的帧会隐藏该图层。

「时间与透明度」里的播放倍率只改变图层取帧速度。要让图层更早退场，可同时缩短持续时长，例如一段 0.8 秒素材以 2 倍速度播放时填 0.4 秒。

扫出横移、纵移和转角以起始位置为基准。比如刀光从 69 度转成 8 度，角度填 69 度，扫出转角填 −61 度，扫动时长填 0.09 秒。图层播放期间按该时长平滑过渡，达到末端后在该处播放余焰和消散。

## 配置演示音效

瓦伦希娜的分镜可以从画布上方的「瓦伦希娜技能」直接选择，再点「查看整招」和「播放」。七项主动招式会同时读取本机已经应用的音轨，另有「预知」闪避演示。点击画布下方「动作与音效时间」里的动作或音效可跳到对应起点。音效区间从该声响开始算到素材播放结束。动作分镜时长单独显示，播放条右端还包含音效尾音。填给游戏的是分镜秒数，原生招式时钟的 5/3 倍速由插件处理。

「处置」合并前后两个分镜工程。`tools/vfx-editor/skill-projects.mjs` 读取模组的 `temp/特效浏览器`，按 `StrikeProfiles.cs` 的穿身突刺与回身前风时长定位接点。收枪、回位和音轨都沿用从起手开始的时钟。浏览器地址加 `?skill=885121` 可直接打开切割攻击，其他招式同理。

重启编辑器后，在画布下方找到「演示音效」。拖动播放头定位，搜索本地音效，点「试听」确认素材，再点「在当前时间添加」。同一段可添加多条音效，将「开始秒」设成同一个值即可叠播。「音量 %」逐条调整，0 为静音，100 为原音量。点某条的「跳转」可从该音效的开始位置继续预览。预览可播放到最长一条音效结束。

每条语音可以设 0.5～2 倍「语速 ×」，时间轴按变速后的时长显示。勾选两条或更多语音的「选入随机组」，点「将勾选语音设为同一随机组」，每次从头播放或循环时从每组各抽一条。新语音也可直接填写已有组号加入该组。暂停后继续沿用本次选择。「试听本条」可以单独听任一个候选。「解除随机组」让同组音轨恢复独立播放。

「字幕」可以手填、换行或清空。已匹配的战斗语音自动带出本地汉化；其他素材默认留空。预览时人物头顶会显示对应语音的文字，同一个人开口说下一句时会替换上一句。

「保存工程」会将画布和音轨设置存入下载的工程副本，包括每条的开始秒、音量、语速、字幕和随机组。编辑器按相对路径识别音频，素材优先从 `mods/boss战 瓦伦希娜/resource/sound` 读取。移动或重命名素材会让保存的工程显示「素材缺失」。透明帧 ZIP 和检查图仍为图像。

需要把搭好的音效用于游戏时，展开「瓦伦希娜技能音效配置」，选目标技能并点「应用到技能」。服务器会写入该模组的 `resource/skill-audio/<技能ID>.json`，若检测到已装插件的测试宿主，也会同步其配置。技能配置使用瓦伦希娜音效库中的素材，开始秒沿用编辑器分镜时间。「载入技能配置」会把该技能已保存的设置填入当前演示音效轨。

## 渲染和对照

```powershell
node tools/vfx-editor/check-scene.mjs "当前.vfx.json" --times 0.18,0.51,0.68,1.02 --time 0.68 --guides --json

node tools/vfx-editor/check-scene.mjs "当前.vfx.json" --reference "参考.vfx.json" --times 0.18,0.51,0.68,1.02 --json

node tools/vfx-editor/check-scene.mjs "当前.vfx.json" --reference "目标.png" --times 0.51,0.68 --json
```

- `--times` 指定最多八个分镜时间点，单位是秒。优先选起手、命中、峰值和收尾。省略时由编辑器根据动作和图层时序取样。
- `--time` 指定 `current.png` 的时间点。省略时取 `--times` 的第一个时间点，单独运行检查时也可只传 `--time`。
- `--reference` 接受另一份工程或不超过 8 MB 的 PNG、WebP、JPEG。工程左右两列按相同秒数渲染，静态参考图在每一行重复显示。
- `--guides` 绘制头顶、身体、脚边的锚点标记。检查纯画面时可以省略。
- 工程中的 `actors.left.cues` 和 `actors.right.cues` 可包含多组 `{ "action": "strike", "at": 0.48 }`，`at` 使用绝对工程秒数。`stage` 可设置 `{ "background": "#848283", "grid": false }`。

## 查看结果

`--json` 返回本机绝对路径和取样时刻。用图片查看工具打开 `comparison` 查看参考在左、当前在右的配对分镜。需要看像素、色彩或锚点细节时打开完整分辨率的 `current`，需要看整段节奏时打开 `timeline`。角色动作及起点、参考类型和取样时刻见 `manifest`。不加 `--json` 时，命令只打印检查记录目录。

人物比例看脚底、头顶和前后排位置。特效检查起手是否对齐杖尖或刀锋、命中帧是否打在目标身上、后续光效何时消退。对照前后版本时，若两个工程引用同一个素材 ID，都会读取当前贴图。替换贴图前先渲染并保存旧版截图作为固定参考。

## 运行条件

使用本机 Node.js 22 或更新版本，以及 Chrome 或 Edge。可用 `VFX_BROWSER` 指定浏览器可执行文件。脚本使用临时浏览器配置和本机 `127.0.0.1`，在受限沙箱中需要相应的本机浏览器和回环访问权限。检查记录位于 `mods/可视化攻击目标/temp/特效编辑器缓存/检查记录/`。

离线自查覆盖编辑器能读取的二维帧、模型姿势和图层编排。Unity 粒子预制体、战斗事件触发以及真实战斗相机效果走游戏内预览验证。
