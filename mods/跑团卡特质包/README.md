## 效果实现口径

- **数值类**（属性/技能/幸运/速度增减）写在 `CreateEvent`，获得特质时一次性生效。
- **奖惩骰类**写在 `WakeEvent`，沉睡时由 `SleepyEvent` 反向收回。
- 卡面里"成功区间 +10"一类没有对应字段的写法，**用技能值 +10 近似**。
- 条件类效果（"数值 ≥50 时 +5，否则 -5"）暂未实现，只保留在描述文案里。

## 怎么改

编辑 `tools\build_traits.ps1` 顶部的特质定义表，然后重跑脚本，`Project_Depersonal` 里的 txt 会重新生成。
**不要直接手改生成的 txt**，下次重跑会覆盖。

```powershell
powershell -File "tools\build_traits.ps1"
```
