# 自定义心：外观编辑器（0.2.1）

> 2026-11-18。自动体型拟合已停用，改为统一默认外观和按调查员保存的手动参数。
> 本文是当前规则；`自定义心-特效随模型缩放调研.md`仅保留历史调研。

## 1. 交互与默认值

- 原编辑面板底部“特效大小和位置”打开模态弹窗。黑色半透明遮罩拦截鼠标，同时禁用主面板和右侧列表；原面板未保存数值保留。
- 预览读取当前调查员实际模型的待机帧和心焰帧动画。坐标轴固定在**游戏原本的特效播放挂点(0,0)**，不是人物中心，也不随火焰移动或缩放。网格间隔0.25，X向右、Y向上。
- 参数：位置X/Y、宽度缩放、高度缩放。宽高相同即等比缩放，也可分别调节。位置范围-10～10，缩放0.01～10；拒绝空值、非数和无穷。
- 应用和重置按钮作为一组居中。应用只更新预览，不保存；重置恢复预设并更新预览，仍须保存才持久化。
- 保存按钮默认可点击，不依赖预览就绪或角色对象自身的编号。点击后校验并保存，成功弹出“保存成功。”确认框；点“确认”后同时关闭提示和特效弹窗，回到原编辑面板。失败展示原因，保留输入。
- 叉号或Esc关闭且不保存；只关闭外观弹窗。原数值编辑面板里的草稿不受影响。

| 参数 | 统一默认值 |
| --- | --- |
| X | 0.05 |
| Y | 0.05（用户最新指定） |
| 宽度缩放 | 0.30 |
| 高度缩放 | 0.30 |

预览和战斗都使用原始挂点的局部坐标及局部缩放。旧底部锚定、欧吉/女孩拟合和世界坐标偏移均已移除。
数据包`Game/ExtraAnim/xin_glow.txt`基础`AnimSize`也改为(0.3,0.3)，本地和订阅模组同步；素材、速度、排序沿用。

## 2. 按调查员保存

用户明确按调查员稳定编号保存，不按模型共用。优先使用角色自身的RoleLibraryKey；幕间该字段可能为空，此时从大厅RoleLibraryData.Key取回：先匹配BaseData对象引用，若为副本只允许唯一同名匹配，同名歧义不保存。

- 文件：`%LocalLow%/MeowNature/Depersonalization-Release/XinEditor/visuals.cfg`，每节`[role_<稳定编号>]`存`X/Y/ScaleX/ScaleY`。
- 与数值配置`hearts.cfg`独立，未保存数值心也能保存外观。缺配置或无有效编号时使用统一默认。
- 应用/重置/关闭不写文件；保存成功才更新缓存，用副本隔离草稿。数值“重置回默认”和移除心特质不会自动删除外观。
- 换模型后仍沿用该调查员参数，可再调节。新开关`[特效] 启用外观参数`默认true，旧`按模型宽度缩放`键已失效。

预览使用独立禁用模型副本读取待机精灵，不调用角色Install，不移动现场角色。心焰用UI Image独立换帧，**不能在UI Image上附加RTECustomAnimConfig**，否则会把共享AnimSize改成1。比例固定135 UI像素/单位，超出预览边界的部分裁切，坐标轴不参与特效变换。
